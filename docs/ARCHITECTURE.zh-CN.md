# 架构设计

[**简体中文**](ARCHITECTURE.zh-CN.md) | [English](ARCHITECTURE.md)

## 设计目标

桥接围绕四个不变量设计：

1. 远程任务必须产生用户可观察的结果。
2. 模型说“完成”不算证据；工具输出和交付回执才算。
3. 供应商或模型变化后，必须先检测并真实调用成功，才能继续执行任务。
4. 凭据不能进入日志、历史、报告、持久化提示词或 Git。

## 组件

### `bridge.js`

统一执行内核，负责：

- 飞书事件归一化和交付；
- Telegram 消息归一化和交付；
- 每会话队列；
- 高风险确认状态；
- Codex CLI 调用；
- 工具证据提取；
- 截图和文件交付；
- 健康检查与重试；
- 任务历史、审计、共享记忆和清理；
- CC Switch/Codex 配置指纹。

### `src/config.js`

加载 `config.json`，支持环境变量覆盖、相对路径和 `~` 路径展开，并验证渠道必填配置。运行数据写入 `storage.dataDir`，不会落到仓库根目录。

### `src/telegram-channel.mjs`

轻量 Telegram 适配器，只负责：

- 长轮询；
- 白名单校验；
- 文本、文件、图片发送；
- `/status` 和 `/reset`；
- 代理和退避。

任务执行统一回调到 `bridge.js`。

### `scripts/capture-screen.ps1`

Windows 截图适配器：截取完整虚拟桌面、计算 SHA-256、返回显示器与窗口元数据。

### `docs/REMOTE_TASK_PROTOCOL.md`

注入到每轮远程任务的安全与验收协议。也可以按配置同步到本机 `AGENTS.md`。

## 任务流程

```text
收到消息
  -> 归一化会话和附件
  -> 每会话队列
  -> 高风险门禁
  -> 确保当前模型真实可用
  -> 运行 codex exec
  -> 解析 JSONL 工具事件
  -> 生成机器核验
  -> 截取完整桌面
  -> 交付文本、截图和文件
  -> 脱敏并写入历史
  -> 清理任务临时文件
```

## 证据门禁

桥接把 Codex JSONL 事件解析成工具调用和输出，并记录：

- 工具调用总数、成功数和失败数；
- 命令退出码和错误特征；
- 是否出现新的可见窗口；
- 截图是否成功、桌面是否锁屏；
- 文本和图片是否交付成功；
- 文件和附件是否成功回传。

当用户可见条件不满足时，模型声称的“完成”会被降级。这样，进程存在、HTTP 200 或 PID 都不会被当作任务成功。

## CC Switch 与模型变化

桥接生成一个不含密钥的配置指纹：

- Codex `config.toml` 内容哈希；
- 当前认证文件哈希；
- 当前供应商和模型；
- 供应商 Base URL；
- CC Switch 当前供应商 ID。

观察器每 `limits.modelWatchMs` 比较一次指纹。

```text
配置指纹变化
  -> 持久化配置快照
  -> 清空绑定旧模型的会话
  -> 等待 modelSwitchSettleMs
  -> 执行最小 ephemeral Codex 调用
  -> 成功：允许任务，刷新健康状态
  -> 失败：阻止任务，健康降级，通知渠道
```

最小实调使用：

```text
codex exec --ephemeral --json --sandbox read-only
```

桥接不传硬编码的 `--model`。供应商可以是官方 API、自建兼容网关、中转站或本地代理；桥接跟随当前 Codex/CC Switch 配置，不维护供应商白名单。

## 健康模型

健康状态由多个独立检查组成：

- 桥接进程；
- 飞书事件消费者；
- 飞书认证/状态；
- Codex 可执行文件；
- 真实模型调用；
- 本地代理或配置端点；
- 桌面截图；
- Telegram 轮询。

真实模型实调是 API 连通性的权威证据。本地代理端口检查只是辅助信号。

## 交付与清理

- 临时任务文件放在任务级临时目录。
- 截图先上传，上传成功后才删除本地副本。
- 正式产物放在配置的输出目录。
- 正式产物按配置时间保留。
- 历史不保存截图本体。

## 凭据处理

在写入以下位置前会应用 `redactSensitiveText()` 和 `redactSensitiveValue()`：

- 日志；
- 任务历史；
- 审计记录；
- 共享记忆；
- 报告摘要；
- 最终用户文本。

它们识别常见 API Key、Bearer、Authorization、GitHub Token、Telegram Token、私钥和 URL 查询参数。脱敏是纵深防御，不是允许把密钥放进提示词。

## 失败语义

桥接优先明确失败，而不是误报成功：

- API 实调失败：任务不启动；
- 截图失败：结果标记为“未完全核验”；
- 图片交付失败：结果降级；
- 文件交付失败：结果标记为部分完成；
- 缺少可见窗口：GUI 任务未核验；
- Telegram 轮询失败：指数退避重试，并在健康检查时报告降级。
